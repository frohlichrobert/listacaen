# listacaen.ro

Listă CAEN Rev. 3, cu căutare și o pagină pentru fiecare secțiune, diviziune, grupă și clasă.

```bash
npm install
npm run build
npm start
```

Pe cPanel, în Setup Node.js App: versiune Node 20 sau mai nouă, fișier de pornire `server.js`. Rulează `npm install`, apoi `npm run build`, apoi repornește aplicația. cPanel trimite portul prin variabila `PORT`.
